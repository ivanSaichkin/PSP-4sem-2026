

# Отчёт по лабораторной работе №1

## Тема работы
Разработка веб-интерфейса калькулятора с адаптивной навигацией и страницей контактов.

## Цель работы
Изучить основы построения современных веб-интерфейсов: создание многостраничного сайта, использование CSS Flexbox для вёрстки, позиционирование элементов, работа с фоновыми изображениями, создание интерактивных кнопок, применение псевдоклассов `:hover` и `:active`.

## Используемые технологии
- **HTML5** — разметка страниц (index.html, contacts.html)
- **CSS3** — стилизация, вёрстка, анимации
- **Flexbox** — построение гибкой структуры хедера, основного контента и футера

---

## 1. Структура веб-приложения

Проект состоит из двух HTML-страниц:

1. **Главная страница (index.html)** — содержит калькулятор
2. **Страница контактов (contacts.html)** — содержит информацию о разработчике и ссылки на соцсети

### 1.1 Общие элементы (Header & Footer)

- **Хедер (header)** — фиксированная навигационная панель (`position: fixed`), которая остаётся видимой при прокрутке. Содержит:
  - Кнопку-иконку для перехода на главную (`home_background.png`)
  - Ссылку на страницу контактов
  - Реализован эффект `backdrop-filter: blur(6px)` — размытие фона под хедером

- **Футер (footer)** — нижний колонтитул с информацией об авторских правах, закреплён внизу страницы (даже при коротком контенте)

### 1.2 Главная страница (Калькулятор)

Калькулятор представляет собой блок с кнопками и полем ввода/вывода.

#### HTML-структура калькулятора (предполагаемая):

```html
<div class="calculator">
    <input type="text" class="result" readonly>
    <div class="buttons">
        <!-- Ряд кнопок: 7 8 9 / -->
        <!-- Ряд кнопок: 4 5 6 * -->
        <!-- Ряд кнопок: 1 2 3 - -->
        <!-- Ряд кнопок: 0 C = + -->
    </div>
</div>
```

### CSS-классы для кнопок:
Класс	Описание
.my-btn	Базовая стилизация: ширина 50px, высота 50px, скругление 25%, фон #ffb319
.my-btn.numbers	Цифровые кнопки: шрифт Times New Roman, увеличенный вес
.my-btn.primary / .secondary	Серый фон для вспомогательных кнопок (очистка, смена знака)
.my-btn.primary.execute	Кнопка "=" — ширина 110px, скругление 14px
### Псевдоклассы:
:**hover** — затемнение фона кнопки

:**active** — увеличение яркости фильтром brightness(130%)

### 2. Общее оформление (CSS)
## 2.1 Фон страницы
```css
body {
    background-image: url('images/background.png');
    background-size: cover;
    background-position: center;
    background-repeat: no-repeat;
    background-attachment: fixed;
}
```
## 2.2 Flexbox-вёрстка для прижатия футера
```css
body {
    display: flex;
    flex-direction: column;
    min-height: 100vh;
}
.content {
    flex: 1;
}
```
## 2.3 Фиксированный хедер с размытием
```css
.site-header {
    position: fixed;
    top: 0;
    left: 0;
    width: 100%;
    backdrop-filter: blur(6px);
    background-color: transparent;
}
```

### 3. Интерактивность и логика работы
## 3.1 Навигация
Переход на главную страницу осуществляется через кнопку с иконкой дома (window.location.href)

Переход на страницу контактов — через обычную ссылку <a>

## 3.2 Работа калькулятора
Судя по стилям и классам, калькулятор должен выполнять базовые арифметические операции:

- Ввод чисел и операторов

- Вычисление результата по нажатию "="

- Очистка поля ввода (кнопка C)

Примечание: В предоставленном фрагменте отсутствует JavaScript для вычислений — это требует доработки.
